### 🙌 使用 Proxifly NPM 模块
使用官方 **Proxifly NPM 模块**，可以在你的应用中轻松获取更新后的代理。

```shell
# 运行此命令安装模块：
npm install proxifly
```


```js
// ESM
import Proxifly from 'proxifly';

// CommonJS
const Proxifly = require('proxifly');
```

```js
const proxifly = new Proxifly({
  // 非必需，但拥有 API Key 可以移除限制（在 https://proxifly.dev 获取你的密钥）。
  apiKey: 'your-api-key'
});
```

```js
// 按你需要的选项抓取代理：
proxifly.getProxy({
  protocol: 'http', // http | socks4 | socks5
  anonymity: 'elite', // transparent | anonymous | elite
  country: 'US', // ISO 国家/地区代码
  https: true, // true | false
  format: 'json', // json | text
  quantity: 1, // 1 - 20
})
.then(proxy => {
  console.log('代理：', proxy);
})
.catch(e => {
  console.error(e);
})
```
