为开发者而生

无论是通过 cURL 快速验证，还是使用 NPM 模块深度集成，Proxifly 都能完美融入您的工作流。

app.js
$ npm install proxifly
// ESM / CommonJS
import Proxifly from 'proxifly';

const proxifly = new Proxifly({
  apiKey: 'your-api-key' // 可选
});

proxifly.getProxy({
  protocol: 'http',
  country: 'US',
  https: true,
  format: 'json',
  quantity: 1
}).then(proxy => console.log(proxy));
