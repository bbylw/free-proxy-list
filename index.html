Integration

用 NPM 或 cURL 接入你的流程

官方 Proxifly NPM 模块可按协议、匿名级别、国家/地区、HTTPS 支持与数量获取代理；也可以直接使用 cURL 下载 TXT 列表。

npm install proxifly

import Proxifly from 'proxifly';

const proxifly = new Proxifly({
  apiKey: 'your-api-key'
});

proxifly.getProxy({
  protocol: 'http',
  anonymity: 'elite',
  country: 'US',
  https: true,
  format: 'json',
  quantity: 1,
});
